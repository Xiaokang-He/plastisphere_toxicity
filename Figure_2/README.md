# Main Fig. 2 — Transcriptomic Functional Enrichment and Apoptosis

## Figure panels and provenance

- **Panel a:** DEG functional-enrichment bubble plots (GO biological process, cellular component and molecular function, and KEGG pathways). An R script will be provided for this panel.
- **Panel b:** GSEA plots for the apoptosis pathway (MAP04210), exported from Majorbio Cloud. These plots were generated by the platform; no R script is provided.
- **Panel c:** Representative TUNEL fluorescence images. This panel consists of microscopy images and is not generated by the Fig. 2 R script.

## Files

- `Fig2.R`: R script for panel a (to be added).
- Figure-specific enrichment result tables required by the script will be stored directly in this folder.

## Run

After the script and input files have been added, run from the repository root in RStudio:

```r
source("Figure_2/Fig2.R")
```
