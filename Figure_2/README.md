# Figure 2 — Transcriptomic Functional Enrichment

- `Fig2a_DEG_Functional_Enrichment.csv`: Fig. 2a DEG functional-enrichment results.
- Fig. 2b GSEA plots were exported from Majorbio Cloud and are not generated by an R script in this repository.

The `Adjusted_P` column contains the values carried over unchanged from the source workbook. The plotting script does not recalculate BH adjustment.

## Reproducing panel a

Run the script from the repository root:

```sh
Rscript Figure_2/Fig2.R
```

Required packages: `ggplot2`, `dplyr`, `readr` and `ggh4x`. Cairo graphics support is required for the PDF export.

The script reads `Fig2a_DEG_Functional_Enrichment.csv` and saves `Fig2a.pdf` and `Fig2a.png` to `Figure_2/results/`.
