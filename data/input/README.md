# Input data

This folder is intentionally kept free of data files in the code-only repository. Place only the input tables needed by the script you intend to run here. The exact filenames are listed in the top-level README.md.

The filenames are the original analysis working-file names. The published Source Data workbooks contain figure-level data, but may not be drop-in replacements for the working tables required by the scripts. Check the column names, sample order, and formats in each script before running it; document any extraction or reformatting step used to obtain an input table.

Do not commit private, restricted, or unpublished data. Confirm that any input file is already publicly available and that redistribution is permitted before adding it to this public repository.
