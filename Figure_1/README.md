# Figure 1 — Physiological and Biochemical Endpoints

`Clam_Physiological_and_Biochemical_Endpoints.csv` contains the sample-level data for Fig. 1a–j: siphoning efficiency, SOD, CAT, GSH, GSH-Px, MDA, AChE, lysozyme, D-Lac and DAO.

The file includes `sample` and an R-compatible `group` field (CTR, MP1, MP10, MPP1, MPP10). The group code was derived from the original sample identifier; measured values are unchanged.

## Reproducing Fig. 1

Run the script from the repository root in a fresh R session:

```r
source("Figure_1/Fig1.R")
```

The script clears the R workspace and automatically installs missing packages from CRAN. Required packages are `dplyr`, `ggplot2`, `ggpattern`, `WRS2` and `svglite`. Cairo graphics support and the Times New Roman font are required for the intended exports.

**Package compatibility:** `ggpattern` requires a compatible `ggplot2` version. If it fails to load with a namespace/version error, update `ggplot2` to meet the installed `ggpattern` dependency and reinstall `ggpattern`.

The main outputs are written to `Figure_1/results/Fig1/`:

- `Fig1_editable.svg`: Illustrator-editable SVG with native text objects.
- `Fig1_editable.pdf`: vector PDF.
- `Fig1_preview.png`: PNG preview.

The same output folder also contains the script backup and parameter/quality-control tables generated by the script.
