# Main Fig. 1 — Physiological and Biochemical Endpoints

## Figure panels

The R script covers panels **a–j**:

- a: Siphoning efficiency
- b: Superoxide dismutase (SOD)
- c: Catalase (CAT)
- d: Glutathione (GSH)
- e: Glutathione peroxidase (GSH-Px)
- f: Malondialdehyde (MDA)
- g: Acetylcholinesterase (AChE)
- h: Lysozyme
- i: D-lactate (D-Lac)
- j: Diamine oxidase (DAO)

Panels **k–m** are representative histological images and are not generated by this R script.

## Files

- `Fig1.R`: R script for panels a–j.
- `Clam_Physiological_and_Biochemical_Endpoints.csv`: input dataset currently specified in the script.

Keep the R script and its input data directly in this folder.

## Run

From the repository root in RStudio:

```r
source("Figure_1/Fig1.R")
```

Generated figures and analysis outputs are written to `Figure_1/results/Fig1/`.

## Requirements

The script checks for its required R packages and installs missing packages when needed. Times New Roman is used for figure text; font availability may depend on the operating system.
