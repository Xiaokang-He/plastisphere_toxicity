# Main Fig. 3 — Proteomic Enrichment and Protein–Protein Interaction Networks

## Figure panels and provenance

- **Panels a–b:** GO and KEGG enrichment analyses of differentially expressed proteins (DEPs), for the microplastic and plastisphere groups, respectively. An R script will be provided for these panels.
- **Panels c–d:** DEP data exported from Majorbio Cloud were submitted to STRING to construct protein–protein interaction (PPI) networks. The networks were then visualized and exported using Cytoscape. No R script is provided for these panels.
- **Panel e:** PGRP immunofluorescence images. This image-based panel is not generated by the Fig. 3 R script.

## Files

- `Fig3.R`: R script for panels a–b (to be added).
- Figure-specific enrichment result tables required by the script will be stored directly in this folder.

## Run

After the script and input files have been added, run from the repository root in RStudio:

```r
source("Figure_3/Fig3.R")
```
