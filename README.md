## Run the scripts

Install the R packages and use an R build with Cairo graphics support for figure export.

```r
install.packages(c(
  "ggplot2", "ggpattern", "WRS2", "dplyr", "readr", "ggh4x",
  "patchwork", "ggalluvial", "cowplot", "vegan"
))
```

Run these commands from the repository root. The linked figure folders list the inputs, packages and output files for each script.

```sh
Rscript Figure_1/Fig1.R
Rscript Figure_2/Fig2.R
Rscript Figure_3/Fig3.R
Rscript Figure_4/Fig4ab.R
Rscript Figure_4/Fig4c.R
Rscript Figure_5/Fig5.R
Rscript Figure_5/Fig5f.R
Rscript Figure_5/Fig5h-k.R
Rscript Figure_5/Fig5l.R
Rscript Figure_6/Fig6.R
Rscript Figure_7/Fig7.R
Rscript Figure_7/Fig7d_Plastisphere.R
Rscript Figure_7/Fig7e_Microplastic.R
```

## Figure inputs

The figure inputs come from the main-figure Source Data workbook and the matched tank-level tables for Fig. 7d–e. See the [data manifest](data_manifest.csv) for each table's source, panels, dimensions and file size in bytes. The manuscript's Data Availability statement provides the sequencing and proteomics accession numbers.
