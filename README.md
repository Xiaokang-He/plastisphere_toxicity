# R Scripts and Figure-Specific Data

This repository contains figure-specific R scripts and input datasets for the study:

*Plastisphere formation reshapes the ecological toxicity of microplastics in Corbicula fluminea.*

## Repository organization

Each main-text figure has its own independent folder. The R script and all input data required for that figure are stored together directly inside the same folder. No separate `scripts/` or `data/` directories are used, and input datasets are not shared between figure folders.

```text
Figure_1/
  Fig1.R
  figure-specific input data
  README.md
Figure_2/
  Fig2.R
  figure-specific input data
  README.md
Figure_3/

  figure-specific input data
  README.md
Figure_4/
  Fig4.R
  figure-specific input data
  README.md

Plastisphere_Microplastic_Toxicity.Rproj
README.md
```

Each figure folder is self-contained. A local `results/` directory is created when a script runs; generated outputs are excluded from version control.

## Figure panels and analysis provenance

| Figure | Panels covered by R scripts | Data processing or visualization performed outside the R scripts |
|---|---|---|
| Fig. 1 | a–j: siphoning efficiency and biochemical endpoints | Panels k–m are representative histological images and are not generated by the Fig. 1 R script. |
| Fig. 2 | a: DEG functional-enrichment bubble plots | Panel b: GSEA plots exported from Majorbio Cloud. Panel c: representative TUNEL fluorescence images. No R script is provided for panels b or c. |
| Fig. 3 | a–b: DEP functional-enrichment plots | Panels c–d: DEP data exported from Majorbio Cloud were submitted to STRING; the PPI networks were visualized and exported using Cytoscape. Panel e: PGRP immunofluorescence images. No R script is provided for panels c–e. |
| Fig. 4 | a–b: nine-quadrant plots; c: correlation heatmap | Correlation coefficients for panel c were calculated and exported from Majorbio Cloud; the R script renders the heatmap. Panels d–e are schematic illustrations. |
| Fig. 5 | a–l: gut microbiota diversity, composition, co-occurrence networks, network topology and robustness | Node and edge data used for panel g were obtained from Majorbio Cloud. Figure-specific code is used for the topology-related outputs, including panel i, as described in the figure-folder documentation. |
| Fig. 6 | Heatmap visualization of KEGG pathway ReporterScores | ReporterScore values were calculated and exported from Majorbio Cloud; the R script renders the heatmap and does not recalculate the scores. |
| Fig. 7 | a–e: gut microbiota–host association panels | Broad network-association data for panels a–c were calculated by Majorbio Cloud; the R script renders the network diagrams. The exact calculation-versus-visualization workflow for panels d–e will be documented with the corresponding script. |

The figure captions define the biological content and panel numbering. Each figure-folder README records the corresponding inputs and the distinction between custom R code and outputs produced using external platforms or software.

## Running a figure

1. Clone or download this repository.
2. Open `Plastisphere_Microplastic_Toxicity.Rproj` in RStudio.
3. Place the input data files directly in the folder for the corresponding figure.
4. Run the figure-specific script from the repository root. For example:

   ```r
   source("Figure_1/Fig1.R")
   ```

5. Generated figures and analysis outputs are saved in the corresponding figure folder's local `results/` directory.
